# Приложение для регрессионного анализа



## Обзор



Интерактивное приложение **R Shiny**, которое автоматизирует весь процесс простого линейного регрессионного анализа.



Приложение позволяет пользователям загружать собственные наборы данных, подбирать регрессионную модель, проводить статистическую диагностику и визуализировать результаты без написания кода.



---



## Особенности



- Загрузка файлов CSV, TXT и Excel

- Выбор зависимой переменной (Y)

- Выбор независимой переменной (X)

- Подбор модели линейной регрессии

- График регрессии с доверительным интервалом

- Анализ остатков

- График «квантиль–квантиль» (Q-Q Plot)

- Критерий нормальности Шапиро—Уилка

- Критерий гомоскедастичности Бреуша—Пагана

- Критерий автокорреляции Дарбина—Уотсона

- Таблица дисперсионного анализа (ANOVA)

- Коэффициент детерминации R² и скорректированный R²

- Доверительные интервалы для коэффициентов модели

- Проверка статистической значимости коэффициентов

## Пример рабочего процесса



1. Загрузить набор данных.

2. Выбрать зависимую переменную (Y).

3. Выбрать независимую переменную (X).

4. Настроить параметры диагностики.

5. Нажать **«Рассчитать»**.

6. Просмотреть результаты регрессионного анализа и диагностики.

## Запуск локально



```r

install.packages(c(

  "shiny",

  "ggplot2",

  "lmtest",

  "car",

  "readxl"

))



shiny::runApp()

```
